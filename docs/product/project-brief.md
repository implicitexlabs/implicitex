# Project Brief

## Name
Implicit Exchange (ImplicitEx)

## What It Is
A USDC transfer service platform.

## Strategic Thesis
ImplicitEx may become financial infrastructure for autonomous agents: a platform for delegated budgets, permissions, identity, settlement, audit, and trust when software transacts and humans supervise.

## Delivery Strategy
- Primary: Online tool (first and fully realized)
- Secondary: Electron desktop software (follow-on phase)
- Tertiary: Ledger hardware wallet integration (after web and desktop stability)
- Strategic expansion: Agent treasury and delegated transaction infrastructure after the current transfer platform is validated

## Priority Statement
Desktop is not the current primary focus.

The agent infrastructure thesis does not expand the immediate MVP; it defines the larger platform narrative to work backward from.
