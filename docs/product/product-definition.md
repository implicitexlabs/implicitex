# Product Definition

## Product Type
USDC transfer service.

## Strategic Direction
Financial infrastructure for autonomous agents, beginning with the current transfer engine and potentially expanding into agent treasury, permissions, identity, settlement, audit, and reputation layers.

## Scope (Current)
Online tool implementation and completion.

## Scope (Later)
Desktop resource derived from online platform behavior.

Agent financial infrastructure remains a strategic initiative, not part of the immediate MVP launch scope.
